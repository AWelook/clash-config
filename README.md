# Mihomo Clash 基础配置

适用于支持 **Mihomo / Clash Meta** 内核的客户端。

## 导入地址

```text
https://cdn.jsdelivr.net/gh/AWelook/clash-config@main/config.yaml
```

备用地址：

```text
https://fastly.jsdelivr.net/gh/AWelook/clash-config@main/config.yaml
```

本仓库只提供基础规则、DNS 和策略组，不包含节点列表。导入后请在客户端另外添加你自己的节点订阅或私有节点提供器。

规则集通过 jsDelivr 加载，首次导入后可能需要等待规则集下载完成。
